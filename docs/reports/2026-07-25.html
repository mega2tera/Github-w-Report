本项目是李博杰所著《深入理解 AI Agent：设计原理与工程实践》一书的开源主仓库，包含全书正文、编译版 PDF、EPUB 电子书及按章节配套的代码实验。书中系统讲解了 AI Agent 的设计原理与工程实践，围绕“Agent = LLM + 上下文 + 工具”的核心公式，分十章逐步展开，涵盖基础知识、上下文工程、用户记忆、工具使用、代码生成、评估方法、模型后训练、持续进化、多模态交互和多 Agent 协作等内容。项目支持多语言版本，配套实验丰富，适合理论学习与实践操作结合。

核心功能

  • 包含 10 章系统讲解 AI Agent 设计与实践的书籍正文和 92 个配套实验项目
  • 支持中文、英文、正体中文、俄语、泰米尔语、越南语和日语七种语言版本
  • 提供 PDF 和 EPUB 格式电子书下载及在线阅读，支持全文搜索和章节折叠
  • 配套代码涵盖从基础知识到多 Agent 协作的多方面实验，部分项目可独立运行

解决的问题

  • AI Agent 设计复杂，涉及多种技术融合，缺乏系统性学习资料
  • 上下文管理和工具调用难以高效实现，影响 Agent 性能和扩展性
  • 多模态交互和多 Agent 协作的工程实践缺少成熟的参考方案
  • 模型训练和持续进化过程中的评估和优化机制不完善

典型应用

3tirth8205/code-review-graph

Local-first code intelligence graph for MCP and CLI. Builds a persistent map of your codebase so AI coding tools read only what matters, with benchmarked context reductions on reviews and large-repo workflows.

本周 +6,565 ★总计 26,255 ★PythonMIT

code-review-graph 是一个基于 Python 的开源项目，利用 Tree-sitter 解析代码库，构建代码的结构化图谱（AST），并通过 Model Context Protocol (MCP) 为 AI 编码工具提供精准的上下文信息，显著减少 AI 在代码审查和大型仓库工作流中的重复读取和计算资源消耗。项目支持多种 AI 编码平台的自动检测和配置，提供命令行工具进行安装、构建和卸载，支持增量更新和持续维护代码图谱。

核心功能

  • 基于 Tree-sitter 构建代码的抽象语法树（AST）图谱，包含函数、类、导入等节点及调用、继承、测试覆盖等边。
  • 通过 MCP 协议向 AI 编码助手提供精确的代码上下文，减少不必要的代码读取，提升效率。
  • 支持多平台自动检测和配置，包括 Codex、Claude Code、GitHub Copilot 等主流 AI 编码工具。
  • 提供命令行工具实现一键安装、构建代码图谱、卸载集成，支持增量更新和自动钩子维护。

解决的问题

  • AI 编码工具在代码审查时往往需要重复读取大量代码，导致资源浪费和效率低下。
  • 大型代码库的上下文信息难以高效管理，影响 AI 代码助手的响应速度和准确性。
  • 不同 AI 编码平台集成复杂，缺乏统一的上下文管理和配置方案。
  • 代码变更后上下文更新不及时，影响 AI 工具的代码理解和建议质量。

典型应用

  • 为使用 AI 代码助手进行代码审查的开发者提供精准上下文，减少无关代码读取。
  • 大型代码库中持续维护代码结构图谱，支持增量更新和快速上下文查询。
  • 多平台 AI 编码工具的统一集成和配置，简化开发者使用流程。
  • 通过上下文图谱辅助代码质量评估和风险分析，提高代码审查效率。

适合谁

  • 软件开发者，尤其是依赖 AI 编码助手进行代码审查和开发的人员。
  • 产品经理和技术负责人，关注提升代码审查效率和降低 AI 计算成本。
  • 创业者和技术团队，寻求在大型代码库中优化 AI 辅助开发流程的解决方案。
  • 开源社区成员和工具集成者，关注多平台 AI 编码工具的兼容和扩展。

差异化特点

  • 基于本地构建的代码结构图谱，避免云端数据泄露和隐私问题。
  • 利用 MCP 协议实现 AI 编码工具的上下文精准传递，显著减少重复读取代码的代价。
  • 支持多种主流 AI 编码平台的自动检测和配置，覆盖面广且易用。
  • 增量更新和自动钩子机制保证代码图谱与代码库同步，提升维护效率。

限制与风险

  • 目前仅支持 Python 3.10 及以上版本，其他语言支持情况未明确。
  • 依赖 Tree-sitter 解析器，支持的语言和语法范围受限于 Tree-sitter 的能力。
  • 初次构建大型项目代码图谱可能需要一定时间（约 10 秒/500 文件），实时性能依赖硬件。
  • 对非 Git 或 SVN 代码库的支持和集成情况未明确。

应用潜力

  • 扩展对更多编程语言和 Tree-sitter 解析器的支持，提升多语言适用性。
  • 增强与更多 AI 编码平台的深度集成，支持更多定制化功能和自动化流程。
  • 优化增量更新和实时监控机制，提升大型项目的响应速度和用户体验。
  • 结合代码质量分析和安全审计功能，提供更全面的代码审查辅助能力。
